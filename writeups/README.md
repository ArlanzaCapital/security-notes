# Write-ups

This directory is reserved for write-ups that are safe and authorized to publish.

Possible content includes:

- original vulnerable applications or experiments;
- intentionally vulnerable training environments where publication is permitted;
- sanitized bug bounty findings after disclosure has been authorized.

Private program details, undisclosed vulnerabilities, credentials, personal data, and confidential target information are not published here.
