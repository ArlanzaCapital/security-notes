# Security Notes

Personal repository for documenting my progress in web security, vulnerability research, and bug bounty.

The goal of this repository is to build a practical knowledge base while improving my methodology for finding, validating, and reporting security issues.

## What you'll find here

- Web security notes
- Recon and testing methodology
- Vulnerability testing checklists
- Notes from legal security labs
- Bug bounty reporting templates
- Sanitized write-ups when public disclosure is permitted
- Small security-related experiments and tools

## Current focus

I'm currently focusing on:

- HTTP and web fundamentals
- Authentication and session management
- Access control vulnerabilities
- API security
- Input validation
- Common web vulnerability classes
- Reconnaissance methodology
- Writing clear and reproducible vulnerability reports

## Repository structure

```text
methodology/   Testing workflows and checklists
notes/         Technical notes by topic
labs/          Notes and lessons from legal practice environments
writeups/      Public or intentionally sanitized write-ups
templates/     Templates for vulnerability reporting
```

## Approach

My objective is not to collect payloads or copy existing cheat sheets, but to document what I understand and build a repeatable testing methodology.

For each topic, I try to answer:

1. What is the vulnerability or security concept?
2. Why does it happen?
3. How can it be identified?
4. How can impact be demonstrated safely?
5. What are common false positives?
6. How should the issue be reported clearly?

## Responsible disclosure

I only publish vulnerability details when I am authorized to do so.

Private program information, confidential targets, credentials, personal data, and undisclosed vulnerabilities are not published in this repository.

Examples based on real findings will be sanitized when necessary.

## Progress

This repository is intentionally a work in progress.

I will continue adding notes, methodologies, lab observations, and public write-ups as I gain practical experience.
